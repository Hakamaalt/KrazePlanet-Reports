## Title
Reflected XSS - settings.pwnedbox.site

## Description
The `settings.pwnedbox.site` endpoint was tested using the `x8scan` tool, which identified multiple GET parameters. The `academy` parameter was found vulnerable to Reflected Cross-Site Scripting (XSS) using a crafted JavaScript payload containing the Unicode escape sequence `\u0061`.

## Steps to Reproduce

1. Open a terminal and execute the following command to discover GET parameters:

   ```bash
   echo "https://settings.pwnedbox.site/" | x8scan -w params.txt
   ```

2. Observe the transformed GET URL generated by `x8scan`, which identifies multiple parameters, including `academy`.

3. Open the following crafted URL in a browser:

   ```text
   https://settings.pwnedbox.site/?academy=hakama%27%22%3CScRiPt%3E\u0061lert(1)%3C/ScRiPt%3E
   ```

4. Allow the page to load.

5. Observe the JavaScript alert dialog displaying `1`, confirming successful JavaScript execution.

6. Dismiss the alert dialog.

**Observed Result:**

The crafted JavaScript payload was executed through the `academy` parameter. The browser displayed a JavaScript alert dialog containing `1`, confirming Reflected Cross-Site Scripting (XSS).

## Impact

- An attacker can craft a malicious URL and trick victims into opening it.
- Successful exploitation allows JavaScript execution in the victim's browser.
- The vulnerability may be abused for phishing or manipulation of displayed webpage content.

## Remediation

- Apply context-aware output encoding to the `academy` parameter before rendering its value in HTML.
- Validate and sanitize user-controlled input to prevent HTML and JavaScript injection.
- Implement a restrictive Content Security Policy (CSP) to block unauthorized inline JavaScript execution.
